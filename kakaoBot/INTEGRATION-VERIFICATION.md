# Mac 단일 프로그램 통합 검증 — 2026-10-21

## 구현 범위

기존 `src/mac-bridge.mjs`의 방 제한·수신함·커서·사진 검증·카카오 송신 검증을 유지하고 `engine.process(event)`를 직접 호출하도록 연결했다. 별도의 `/events` HTTP 왕복과 OCI 봇 프로세스는 제거했다. `src/server.mjs`, OCI용 PM2 설정을 제거했으며 `npm start`가 Mac 통합 프로그램을 실행한다.

사진 분석과 텍스트 요청은 모두 회사의 `gemma4:26b`를 사용한다. Qwen 커스텀 API는 호출하지 않는다. Mac 프로그램이 Tailscale SSH 터널을 자식 프로세스로 실행·복구·종료한다. SSH는 `HostName=100.92.167.33`을 명시하고 `127.0.0.1:28006 → OCI 127.0.0.1:28004`만 전달한다.

이미지 검증은 개인 사진을 회사 AI로 보내지 않고 저장소의 합성 PNG 2장으로 수행했다. 기대 코드·날짜·원 개수는 모델 질문에 포함하지 않았다. 인증서 검증을 유지했다. 상세 결과는 로컬 `data/verification/gemma-vision.json`, `gemma-draft.json`에 있으며 Git에서 제외된다. 이미지 초안에는 행사 일정과 공고 게시 기간이 별도로 보존됐다.

기존 카카오 실제 텍스트·원본 JPEG 수신·자동 방 열기·송신 DB 확인은 이전 단계에서 완료했다([MAC-VERIFICATION.md](MAC-VERIFICATION.md)). 이번 통합 이후의 **실제 사이트 DB 답변 및 사진 게시물 등록은 아직 성공 검증하지 않았다.** 새 사용자 이벤트에 대한 통합 엔진의 카카오 응답도 사용자 테스트 입력 후 확인해야 한다.

## 자동 테스트

`npm test`: 26개 통과. `npm run bridge:check`: 통과, `appConfigured=false`를 정확히 표시했다. LaunchAgent 템플릿은 `plutil -lint` 통과했고 설치 도구의 문법을 검사했다. 자동 시작은 설치하지 않았으며 GUI LaunchAgent 문맥의 권한·송신은 미검증이다.

- 숫자 ID의 문자열 정밀도, 테스트방 외 처리 금지, 자기 발신·동시 중복 이벤트 제외.
- 사진 원본 URL·DNS·로컬 경로·이미지 형식·크기·해상도·장수·합계 제한.
- 직접 엔진 호출에 원본 Base64와 정확한 ID가 전달되는지 확인. 중계 HTTP 서버는 사용하지 않음.
- 사진만 수신하거나 등록을 거절한 요청은 분석·등록하지 않음.
- 같은 사용자라도 다른 방의 사진을 섞지 않음. 다른 사용자 사진도 분리.
- 누락/충돌/잘못된 날짜 질문, 취소·만료·재시작 후 일반 사진 세션 폐기.
- AI 장애의 안전한 안내, 검색 조건 계약, 숨김·삭제 결과 및 비공개 필드 제거.
- 명시적인 중복 등록 확인과 별도 키 사용.
- 모의 사이트가 게시물 생성 직후 응답을 유실하는 상황에서 완전 재시작 → 동일 키·사진·초안 재사용 → 추가 게시물 생성 없음.
- 등록 성공 후 카카오 송신이 불명확해도 재등록·자동 재송신 없음.
- 별도의 DB 잠금으로 프로그램 중복 실행 방지.

서버의 실제 DB 트랜잭션·BotPublication 유일 키·공개 조회 필터는 **운영 사이트에서 검증되지 않았다.** 자동 테스트에서는 계약을 지키는 모의 사이트로 확인한 범위다.

## OCI에서 필요한 변경

운영 `/home/ubuntu/app/apart/front`의 확인 커밋은 `00d3999`다. 사이트 28004는 실행 중이나 봇 API·BotPublication 스키마/migration·APP_BOT_SECRET·BOT_AUTHOR_ID를 찾지 못했다. Mac APP_BOT_SECRET도 비워 두었으며 임의 회원이나 관리자 계정을 선택하지 않았다.

Windows의 원래 API 코드를 확인해 배포하고, 전용 작성자와 공유 비밀값을 준비해야 한다. 요청·응답 계약과 배포/검증 요구사항은 [OCI-HANDOFF.md](OCI-HANDOFF.md)에 정리했다. 운영 코드·환경변수·DB·다른 프로젝트에는 변경하지 않았다. 사용자가 전달 대상으로 지정한 채팅은 SUJIKTOP의 `카카오 챗봇 사진 검토 및 DB 답변`이다. 현재 세션의 도구에서 SUJIKTOP이 연결된 채팅 호스트로 확인되지 않아 아직 전송하지 못했다. SUJIKTOP 호스트 연결 또는 해당 채팅 링크/ID로 접근 가능 여부를 확인한 뒤 전달해야 한다.

- `src/mac-bridge.mjs`: 기존 수신/송신 유지, 엔진 직접 연결, 단일 실행·SSH 생명주기.

- `src/store.mjs`: 답변 캐시·등록 intent/결과의 영속 저장과 사진/초안 정리.
- `src/tunnel.mjs`, `src/process-lock.mjs`, `src/errors.mjs`: 터널·중복 실행·안전한 오류 코드.
- `scripts/check-ai.mjs`, `scripts/status.mjs`, `scripts/service.mjs`: 실추론·복구 상태·자동 시작 도구.

- `.env.mac`(0600, Git 제외), 설정 예제·package.json·터널/LaunchAgent 템플릿·README.

아직 완료하지 못한 운영 검증은 실제 공개 DB 질문 답변, 사진 업로드 후 사이트 게시물 생성, 게시물 링크 확인, 실제 서버에서 숨김/삭제 제외와 응답 유실 복구, 자동 시작 문맥의 송신이다.

검증용 foreground 프로그램은 정상 종료했으며 자동 시작은 등록하지 않았다. 새 테스트 메시지로 통합 엔진의 실제 카카오 응답을 확인하려면 `npm start`로 실행한 후 다른 참여자 계정에서 호출해야 한다.
