# UI 구현 가이드

2026-10-13. 기존 `plan/UI-스타일가이드.md`와 이후 사용자가 요청한 디자인을 통합한 관리 기준이다. 이 문서를 Git으로 관리한다.

## 공통 규칙

- 페이지 제목 20px, 섹션 제목·입력값 16px, 본문·일반 버튼 14px, 보조 정보 12px. 제목 700, 기본 버튼 600, 본문 400. 기본 줄 간격 1.5.
- 버튼·단독 링크는 실제 터치 영역 최소 44×44px. 작은 아이콘을 써도 클릭 영역은 줄이지 않는다. 텍스트 안의 링크는 예외다.
- 버튼·입력·사진·패널 모서리 4px. 일반 패널에 그림자를 넣지 않는다. 지도 말풍선·핀·지도 도구의 그림자와 캡슐은 지도 전용 예외다.
- 기본 글자 `#202722`, 보조 `#626b65`, 구분선 `#dde2de`, 브랜드 `#206444`.
- 입력 배경 `#f3f5f4`, 안내 `#89938c`. 제보와 내 정보는 같은 규칙을 쓴다. 텍스트 필드 규칙을 checkbox/radio/hidden/range에 적용하지 않는다.
- 주요 버튼은 브랜드 배경과 흰 글자. 보조 버튼은 `#f3f5f7/#475569`, 선택은 `#ddf5e6/#075b3a`. 버튼 테두리는 쓰지 않고 포커스 outline은 유지한다.
- 카카오 노란색, 분류 색상, 좋아요 색상, 사진 조작부의 반투명 배경은 기존 승인된 역할 색상으로 유지한다. 새 임의 색상은 공통 토큰으로 정의한다.
- 기본 아이콘 20px. 상세 상태 버튼의 원형 체크/X 28px, 지도 핀, 사진 뷰어 확대 조작은 기능상 크기 예외다.

## 화면과 배치

- 모바일 기준은 760px 이하. 기본 좌우 여백 16px, 데스크톱 32px. 피드는 360px 이하에서 8px 여백을 허용한다.
- 피드·내 정보·제보의 데스크톱 콘텐츠 폭은 680px이며 바깥 패딩을 합친 wrapper는 744px이다. 홈 바깥 폭은 1180px이다.
- 피드는 왼쪽 사진, 오른쪽 일정 태그·등록 시각·분류·제목·본문·일정·현장 확인 순서. 본문 최대 3줄. 하단에 좋아요·댓글·공유를 둔다.
- 사진 클릭과 제목/본문 클릭은 상세를 연다. 사진의 지도 버튼은 왼쪽 위, 확대 버튼은 오른쪽 아래다. 실제 좌표가 없는 글과 공고에는 지도 버튼을 표시하지 않는다.
- 상세·확인 기록·계정 설정은 같은 dialog 헤더·제목·X·바깥 클릭·Escape·포커스 복원 규칙을 쓴다. 상세 헤더에 공유 버튼을 중복 배치하지 않는다.
- dialog는 데스크톱 상단 중앙·최대 1000px, 모바일 전체 화면이다. 상세 본문만 데스크톱 2열, 모바일 1열이다.
- 사진 뷰어는 확대·이동을 위한 전용 전체 화면 dialog다. 다른 dialog 본문 스타일과 합치지 않는다.
- 홈 바로가기는 이동 링크이며 고정 선택 상태를 표시하지 않는다. 피드 분류와 하단 메뉴만 현재 선택을 표시한다.

## 상태·일정·조회

- `오늘 와요 / 오늘 안와요`는 예정 일정 태그다. 실제 상태를 의미하지 않는다.
- 현장 확인 문구는 `있어요 / 없어요`다. 상세는 체크/X 아이콘과 보조 문구를 함께 표시한다. 실제 선택 상태는 해당 버튼 배경으로 구별한다.
- 상세의 `마지막 확인: 날짜 + 있어요/없어요 태그`를 누르면 기록을 연다. 최신 기록이 지난 회차여도 읽을 수 있다. 28일 이상 된 기록만 오래된 제보로 표시한다.
- 피드·상세의 확인 버튼은 유지한다. 지도에서는 이번 회차 확인 후 버튼을 숨기고 기록 진입은 유지한다. 숨김 글은 기록 열람 권한을 유지하되 현장 확인 버튼은 비활성화한다.
- 빈 요일은 방문 요일 미정이다. 기존 정책대로 선택한 계절의 모든 날짜 목록에 포함한다. 제보 입력 안내에서 이를 설명한다.
- 오늘 목록은 한국 달력 날짜의 일정 기준이다. 자정 넘는 실제 확인은 이전 방문 회차에 속할 수 있다. “현재 영업 중” 목록으로 해석하지 않는다.
- 더보기는 중복 실행을 막고, 탭 전환 시 이전 응답을 버린다. 같은 목록을 갱신할 때 이미 읽은 페이지 범위를 유지한다.

## CSS 변경 규칙

- `globals.css`의 원래 컴포넌트 블록을 수정한다. 파일 끝에 수정용 선택자를 추가하지 않는다.
- 역할이 같은 요소는 공통 클래스와 토큰을 쓴다. 상세 본문 2열, 지도 좌표, 이미지 확대 등 실제 기능 차이만 전용 클래스로 둔다.
- 반응형 규칙은 같은 760px 기준을 쓴다. 피드 360px·시간 선택 container query처럼 목적이 분명한 경우만 추가한다.
- 변경 후 계산된 스타일을 검사한다. width만 28px로 지정해도 min-width가 44px이면 실제 폭은 44px이므로 소스 숫자만으로 판정하지 않는다.
- 최소 검증 폭은 320·390·720·1440px. 가로 잘림, 버튼 겹침, 모달 헤더 일치, 입력과 키보드 포커스를 확인한다.
