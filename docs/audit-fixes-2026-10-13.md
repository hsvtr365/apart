## 설치·운영

`cd front && npm run db:migrate`가 공식 설치 명령이다. 빈 DB에서는 역사적 notice_period migration의 의존 순서만 보정한다. 전체 public schema가 비어 있지 않으면 초기화하지 않으며 기존 DB를 reset하지 않는다. 실패한 이전 수동 설치가 남아 있는 DB는 자동 삭제하지 않는다.

Linux 운영의 기존 일일 cron은 유지한다. Windows에서 상시 운영하는 경우 작업 스케줄러에 `npm run cleanup:accounts`를 하루 한 번 등록해야 한다. 개발용 PC에 예약 작업을 자동 생성하지 않는다. 운영 대상은 기존 Linux PM2 서버다.

가이드는 [UI 구현 가이드](ui-guide.md)를 Git으로 관리한다. 오래된 로컬 plan 문서는 이 문서를 참조하도록 갱신한다. 사진 왼쪽 배치·사진 위 도구·현장 상태 문구 등 최근 사용자 요청을 유지한다.

## 검증

- 단위 검사: 이미지 동시 생성·캐시 재사용을 포함해 20개 통과.
- 격리 DB/API: 빈 DB 설치와 재실행, 탈퇴/삭제 잠금을 기다리던 쓰기 차단, 로그·권한·회차·페이지·중복 좋아요·만료 정리 통과.
- 브라우저 자동 검사 4개 통과: 활동 지연 응답·분류 전환·초안·댓글 페이지 유지·기존 화면 흐름 확인.
- 최종 타입 검사와 운영 빌드 통과.
- Chromium 320·390·720·1440px에서 가로 넘침 없음. 상세/기록 헤더는 모바일 56px, 데스크톱 64px로 일치. 320px에서 사진 지도·확대·현장 확인·기록 버튼의 최소 44×44px 영역 확인.

## 유지한 정책과 한계

- 오늘 목록은 예정 방문일 기준이며 밤을 넘긴 실제 확인 회차와 다를 수 있다. 지도에서 확인 후 버튼을 숨기는 기존 정책도 유지한다.
- 닉네임/좋아요 보관기간과 계정 익명 표시 규칙은 유지한다. 카카오 자동 연결 해제·정식 약관 작성은 이번 감사 조치 범위가 아니다.
- 실기기 iOS/Safari·부하 테스트는 수행하지 않는다. UI 검증은 Chromium 기준이다.
