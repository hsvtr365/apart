# 공고 종류

- 홈페이지 제보·수정에서 단기/일상을 선택한다.
- 시작일부터 달력 기준 한 달 이상이면 일상(ROUTINE)으로 자동 저장한다. 한 달 미만은 단기(SHORT)가 기본이며 일상으로 직접 선택할 수 있다.
- 월말은 다음 달 마지막 날로 맞춘다. 1월 31일~2월 28일은 평년에 한 달이다.
- Post.noticeKind는 공고만 SHORT/ROUTINE을 저장하며 다른 카테고리는 null이다.
- 기존 공고 migration은 같은 날짜 규칙을 적용한다. 사용자가 지정한 주차 단속·공사협조·화분 투척 금지 안내는 일상으로 보존한다.
- 봇은 같은 필드를 등록하고, 내부 검색 API noticeScope=SHORT/ROUTINE/ALL을 사용한다. 기본 SHORT이며 SQL 조회 단계에서 적용한다. 홈페이지 피드는 두 종류 모두 유지하고 상세 상태에 종류를 표시한다.
- 운영 반영: DB 백업 → npm run db:migrate → npm run build → PM2 apart 재시작 → API·화면 검증. migration은 필드 추가/분류만 수행하고 글 내용·사진·작성자·공개 여부를 바꾸지 않는다.
- Mac 봇은 터미널에서 다시 실행해야 변경된 소스를 읽는다. 진행 중인 등록 보완 대화는 재시작 시 초기화될 수 있다.

검증: 사이트 validation·타입 검사·빌드, 격리 DB 봇 API 계약, 모바일 폼 Playwright, Mac 봇 테스트.
